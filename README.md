# Peevers Consulting Services website, v3

One static page, `index.html`, plus `headshot.jpg`. No build step and no config.

## Preview locally
Open `index.html` in a browser.

## Deploy on Vercel (when ready)
1. Create a new Vercel project and upload this folder, or push it to a GitHub repo and import it.
2. Framework preset: "Other". No build command, output directory is the folder root.
3. Add a custom domain in the project's Domains settings.

Note: Vercel's Hobby plan is for non-commercial use, so a business site belongs on Pro.
